星表探测与自主导航数据集汇总

> 面向星表探测、跨视角定位、多传感器融合 SLAM、三维重建与自主勘查的科研数据集整理。

本仓库用于持续收集和整理科研项目中使用或关注的公开数据集，方便查找数据来源、了解数据内容、比较适用任务，并记录下载与使用注意事项。

## 1. 数据集分类
本仓库按照主要研究任务，将数据集分为四类：

1. 轨道—巡视跨视角定位数据集：轨道遥感影像与巡视器近场影像匹配、跨尺度视觉定位、全局地理定位等。
2. 多传感器融合定位与建图数据集：激光雷达、相机、IMU 等传感器融合，适用于视觉里程计、激光里程计与 SLAM 算法评测。
3. 星表目标检测与语义分割数据集：地形高程、点云、影像及语义标注，适用于三维重建、地形分析和地图构建。
4. 资源勘查数据集：星表光谱观测、资源分布和勘查任务相关数据。
